# Mall 系统接口性能测试报告

## 1. 测试目的
评估 Mall 系统登录与品牌列表接口在 50 并发下的性能表现，分析系统资源占用情况。

## 2. 测试环境
- 服务器：阿里云 ECS 2核4G Ubuntu 22.04
- 被测系统：Docker Compose 部署的 Mall 系统
- 压测工具：Apache JMeter 5.6.3 (命令行模式)
- 监控工具：Prometheus + Grafana + Node Exporter

## 3. 测试策略
- 并发用户数：50 线程
- Ramp-up：10 秒
- 持续时间：300 秒 (5分钟长稳测试)
- 循环方式：持续压测，直到时间结束

## 4. 测试结果（核心指标 - 数据来自 JMeter HTML 报告）
